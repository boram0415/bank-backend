## 막힌 것 / 해결
- 필드명 `users → user`, 타입 `Long → BigDecimal`로 바꾸고 생성자를 안 고쳐서 컴파일 에러 3개 발생
  → 리팩토링 시 **필드/파라미터/`this.` 3세트를 같이 봐야 한다**는 걸 체감
- `@ManyToOne`의 fetch 기본값이 `EAGER`인 걸 처음 알았음. 그대로 두면 N+1 쿼리 위험
  → `fetch = FetchType.LAZY` 명시로 해결
- 잔액을 `Long`으로 뒀다가 금융 도메인 표준인 `BigDecimal`로 교체 (부동소수점 오차 방지 + 이자·수수료 소수 대응)
